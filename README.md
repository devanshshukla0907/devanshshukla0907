## Proof of Work 

### Enterprise AI & Agentic Systems

* **[AI-Powered Active Learning Platform](https://github.com/devanshshukla0907/AI-POWERED-ACTIVE-LEARNING-PLATFORM.git)**
  * **Tech Stack:** Node.js, React, Gemini 2.0, MediaPipe WASM, AWS, Docker
  * **Details:** A 4-tier microservices architecture integrating Gemini for auto-generating mind-maps. Uses MediaPipe WASM for zero-latency, in-browser cognitive load tracking.

* **[AyuAI (Neuro-Symbolic Health OS)](https://github.com/devanshshukla0907/Aayu.ai-Mobile-Application.git)**
  * **Tech Stack:** FastAPI, Python, InceptionV3, LangChain, RAG, Supabase
  * **Details:** 1st Prize, Hack KRMU 5.0. Engineered a strict RAG pipeline to ground LLM dietary recommendations in a verified medical database, eliminating generative AI hallucinations.

### Physical AI & Edge Computing

* **[Aarohan (AI Sports Assessment)](https://github.com/devanshshukla0907/Aarohan..git)** * **Tech Stack:** Django, React, OpenCV, MediaPipe
  * **Details:** 1st Prize, NSUT DevXpo. An athletic biomechanics platform utilizing computer vision and pose estimation pipelines to track joint angles and movement efficiency in real-time.

### Finance & Research

* **[SIT Asset Allocation (DSFM)](https://github.com/devanshshukla0907/sit-asset-allocation-dsfm.git)**
  * **Tech Stack:** PyTorch, Signatory, Pandas, yfinance
  * **Details:** Replicated and extended a state-of-the-art Signature-Informed Transformer. Integrates multimodal sentiment signals (VIX, FRED News) to predict risk-adjusted allocations.

* **[Options Pricing Research](https://github.com/devanshshukla0907/OPTIONS_DATA.git)**
  * **Tech Stack:** Python, Pandas, NumPy, SciPy, Financial APIs
  * **Details:** Deep dive into advanced mathematical modeling, historical options data analysis, and stochastic calculus for derivative pricing.

* **[Fantasy 11 Prediction Engine](https://github.com/devanshshukla0907/fantasy11cricketteamprediction)**
  * **Tech Stack:** Python, Scikit-Learn, Pandas
  * **Details:** Data-driven sports analytics model for optimizing fantasy league team selections based on historical player heuristics.

### Open Source Infrastructure & Tooling

* **[PyLogStream](https://github.com/devanshshukla0907/pylogstream)**
  * **Tech Stack:** Python, WebSockets, Asyncio
  * **Details:** A lightweight, asynchronous Python logging utility designed to stream logs directly to WebSockets or HTTP endpoints for real-time microservice monitoring.

* **[Venv-Forensics](https://github.com/devanshshukla0907/venv-forensics.git)**
  * **Tech Stack:** Python, OS/Sys Modules, Shell
  * **Details:** A security and auditing tool built to dissect and analyze Python virtual environments for dependency vulnerabilities and environment drifts.
